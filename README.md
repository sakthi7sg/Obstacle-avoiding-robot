\# Obstacle-Avoiding Robot



University of Hertfordshire - BEng (Hons) Robotics and AI

Module: Applied Robotics and AI Project



\## Project Description

A mobile robot that detects obstacles using an ultrasonic sensor and

automatically stops, turns and navigates around them.



\## Hardware / Simulation

\- Arduino Uno

\- Ultrasonic sensor (HC-SR04)

\- Motor driver (L298N)

\- 2 DC motors with wheels, chassis and battery pack

\- Simulation: Tinkercad / Wokwi
